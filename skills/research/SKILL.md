# `/research` compatibility entry

This is a legacy compatibility route for the router at
`skills/skills-codex/research/SKILL.md`. The default profile uses the separate
`/autoresearch-topic` and `/autoresearch-proposal` entries. Route topic input
to the former and an existing application draft to the latter.

Do not implement a second search flow here. The four canonical entries own the
Zotero semantic-search contract, terminal query statuses, coverage policy,
branch audit, promotion gate, and synthesis handoff.
