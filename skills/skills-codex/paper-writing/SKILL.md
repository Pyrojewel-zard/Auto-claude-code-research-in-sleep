# Legacy paper-writing compatibility entry

The reduced Codex surface uses `/autoresearch-topic` or
`/autoresearch-proposal` → `/research-audit` → `/research-write`. Use
`skills/skills-codex/research-write/SKILL.md` for all new paper authoring: it requires
promoted evidence, separates observed from inferred claims, records
`OBLIGATIONS.md`, freezes inputs, and hands the result to an isolated Anti
audit.

Use this entry only when a historical workspace explicitly depends on the old
multi-stage paper pipeline. Before producing new load-bearing prose, migrate
its research artifacts to the `/research-write` contract and run the pre-draft gate.
